# make-knowledge-cards

把一篇文章变成 5~8 张知识卡片。

## 1. 项目解决什么问题

读过的文章留不下印象：收藏了等于读了，划线了等于记住了。`make-knowledge-cards` 解决"读完就忘"的问题——把一篇长文自动提炼成 5~8 张结构化知识卡片，每张只讲一个知识点，读完文章后可以直接拿卡片复习、自测，把"看过"变成"记住"。

它是一个 [WorkBuddy Skill](.workbuddy/skills/make-knowledge-cards/SKILL.md)：把用户粘贴的文章/文本，或本地 TXT 文件，提炼成知识卡片。每张卡片包含**标题、核心知识、简明解释、例子或自测问题**。

## 2. 主要功能

- **一卡一知识点**：提炼原文中真正重要的知识，一张卡片只讲一个知识点，重复内容只保留一次
- **固定卡片结构**：标题（结论式）、核心知识（一句话 ≤40 字）、简明解释（2~4 句）、例子或自测问题
- **不编造**：所有内容（含例子和自测问题）均以原文为依据，不做原文没有的扩展
- **不凑数**：信息不足时按实际可提取数量输出（可少于 5 张），绝不为凑满 8 张而注水
- **双输入源**：支持对话中直接粘贴文本，或指定本地 TXT 文件路径（UTF-8 / GBK）
- **零依赖**：无脚本、无第三方库，只需一个能读文本的 AI 助手

不支持的输入：网页抓取（URL）、PDF / Word 等非 TXT 格式、Anki 导出（.apkg）、图形界面。

## 3. 安装方法

本 Skill 无需构建或安装依赖，把技能目录放进 WorkBuddy 的技能目录即可：

**方式一：项目级**（仅当前项目可用）

```bash
# 若已在项目根目录（含 .workbuddy/skills/make-knowledge-cards/），则无需任何操作
```

**方式二：用户级**（所有项目可用）

```bash
# 把技能文件夹复制到用户技能目录
cp -r .workbuddy/skills/make-knowledge-cards ~/.workbuddy/skills/
```

安装后重启对话即可生效。说"把这篇文章做成知识卡片"即可自动触发；也可以配合 `agents/openai.yaml` 在其他支持 OpenAI Agents 格式的框架中声明本技能。

## 4. 使用方法

### 方式一：直接粘贴文章

```
请把下面这篇文章做成知识卡片：
<粘贴文章全文>
```

### 方式二：指定本地 TXT 文件

```
把 /path/to/你的文章.txt 做成知识卡片
```

输出默认直接显示在对话中；输入为 TXT 文件时会另存为 `知识卡片_<原文件名>.md`（与原文件同目录，或用户指定目录）。

## 5. 输入输出示例

**输入**（`sample_tech.txt`，一篇讲费曼学习法的文章）：

```
费曼学习法：为什么"教别人"是最好的学习方式
很多人学完一门课程后感觉自己"懂了"，但一动手就卡壳……
```

**输出**（`知识卡片_sample_tech.md`，节选）：

```markdown
## 卡片 1 ｜标题：不能用简单语言讲清一个概念，说明还没真正理解它

**核心知识**：费曼学习法的核心判据——能讲给外行听，才算真懂。

**简明解释**：很多人上完课"感觉懂了"，动手却卡壳，这是"假懂"。
费曼方法用"能否用简单语言讲给完全不懂的孩子"作为检验理解的标准。

**自测**：为什么"看懂了讲解"不等于"理解了概念"？
（答案：看懂只是识别，能独立复述才证明可以在脑中重构整个因果链。）
```

更多完整示例见 [test/](.workbuddy/skills/make-knowledge-cards/test/) 目录（技术类文章 → 6 张卡片；短篇叙事 → 4 张卡片）。
